# Government Scheme Chatbot

## Project Description
Government Scheme Chatbot is a mini AI-based chatbot application developed using FastAPI and Streamlit. It helps users retrieve government scheme information through a real-time chat interface.

## Technologies Used
- Python
- FastAPI
- Streamlit
- JSON
- Uvicorn

## Features
- Real-time chatbot UI
- Government scheme retrieval
- FastAPI backend APIs
- Query logging
- Admin access control
- Error handling

## APIs
- /search
- /admin

## Run Project

### Backend
python fastapi_app.py

### Frontend
streamlit run streamlit_app.py
